# 게임 기획서 — 라인 밸런싱 퍼즐

> 4차시 Claude Code 실습용 레퍼런스. 이 문서를 그대로 에이전트에 주고 "기획서대로 만들어 줘" 형태로 사용.
> 교육용 가상 회사·가상 데이터. (가상) 동백정밀, 실존 기업·인물과 무관.

## 1. 목표

- 작업요소를 스테이션(작업자 1명이 맡는 구간)으로 묶어 **모든 스테이션 시간 ≤ 택트타임** 달성
- 그 조건을 **가장 적은 스테이션 수**로 달성할수록 높은 평가
- 학습 목표: 택트타임 · 병목 · 일 생산능력 · 라인 밸런싱 효율을 손으로 움직여 보며 체감
- 결과물: 브라우저에서 바로 열리는 **HTML 파일 1개** (`결과/라인밸런싱게임.html`)

## 2. 대상

- 사용자: 생산관리·현장 관리자 (게임 경험 무관, 마우스 또는 터치만 사용)
- 사용 환경: PC 브라우저(Chrome·Edge) 우선, 모바일 폭(390px)에서도 조작 가능
- 사용 시간: 레벨당 3~5분

## 3. 규칙

| 항목 | 규칙 |
|---|---|
| 작업요소 순서 | 고정. 앞 요소가 끝나야 다음 요소 시작(선행 관계) |
| 스테이션 | 연속된 작업요소 묶음. 순서를 건너뛰는 묶음 불가 |
| 스테이션 시간 | 묶인 작업요소 표준시간의 합 |
| 택트타임 | 가용시간(초) ÷ 하루 수요(개) |
| 병목 | 스테이션 시간이 가장 긴 스테이션 (같은 값이 여럿이면 모두 표시) |
| 일 생산능력 | 가용시간(초) ÷ 병목 스테이션 시간 → 소수점 아래 버림 |
| 라인 밸런싱 효율 | 작업요소 합계 ÷ (스테이션 수 × 병목 시간) × 100, 소수점 1자리 반올림 |
| 클리어 | 모든 스테이션 시간 ≤ 택트타임 |

- 가용시간 = 2교대 × 조당 450분 × 60 = 54,000초 (두 레벨 공통)
- 한 작업요소가 택트보다 길면 해당 레벨은 클리어 불가 → 레벨 데이터에 그런 요소 넣지 않음

## 4. 화면 구성

위에서 아래 순서. 한 화면(1280×800)에 스크롤 최소.

| 영역 | 내용 |
|---|---|
| 상단 바 | 게임 제목 · 레벨 선택(1·2) · 레벨 설명(대상 셀·수요·가용시간·택트) |
| 작업요소 띠 | 작업요소 카드 가로 나열(이름·초). 같은 스테이션 = 같은 색. 카드 사이 **경계 버튼** |
| 스테이션 막대 차트 | 스테이션별 세로 막대(작업요소별 구간 누적) · **택트 가로 점선** · 택트 초과 막대 빨간색 · 병목 막대 굵은 테두리 + "병목" 표시 |
| 지표 카드 | 스테이션 수 · 병목 시간 · 택트 · 일 생산능력(수요 대비 ±) · 밸런싱 효율 · 점수 · 별 |
| 흐름 보기 | 스테이션 상자 가로 배치, 상자 앞 대기 부품 더미 · 경과 시간·투입·완성 수 |
| 안내 줄 | 현재 상태 한 줄 메시지 (예: "스테이션 3 택트 초과 3초") |

- 색: 정상 막대 = 파랑 계열, 택트 초과 = 빨강, 택트선 = 짙은 회색 점선
- 숫자는 천 단위 쉼표, 초는 정수 또는 소수 1자리

## 5. 조작

| 동작 | 결과 |
|---|---|
| 카드 사이 경계 버튼 클릭(탭) | 경계 있음 ↔ 없음 전환 = 스테이션 나누기·합치기 |
| 되돌리기 버튼 | 직전 조작 1단계 취소 (여러 번 가능) |
| 처음 배치 버튼 | 레벨 시작 배치(현재 현장 배치)로 복귀 |
| 레벨 선택 | 레벨 전환 시 해당 레벨 시작 배치로 초기화 |
| 흐름 보기 ▶ / ■ | 흐름 애니메이션 시작·정지 · 속도 선택(×10 · ×30 · ×60) |

- 조작할 때마다 차트·지표·별 즉시 갱신
- 키보드: 경계 버튼 Tab 이동 + Enter/Space 전환

### 흐름 보기 동작

- 부품 투입 = 택트 간격(수요 속도)으로 첫 스테이션 앞에 1개씩
- 각 스테이션 = 한 번에 1개, 스테이션 시간만큼 걸린 뒤 다음 스테이션 앞으로 이동
- 택트보다 느린 스테이션 앞에 대기 부품이 계속 쌓이는 모습이 보여야 함 (병목 체감)
- 모든 스테이션이 택트 이하면 대기 부품이 쌓이지 않음
- 화면 표시: 경과 시간(초) · 투입 수 · 완성 수 · 스테이션별 대기 수

## 6. 점수

| 항목 | 기준 |
|---|---|
| 점수 | 클리어 시 밸런싱 효율(소수 1자리) × 10 (예: 효율 80.0% → 800점) · 미클리어 0점 |
| ★ | 클리어 (모든 스테이션 ≤ 택트) |
| ★★ | 클리어 + 최소 스테이션 수 |
| ★★★ | ★★ + 그 스테이션 수에서 가능한 가장 작은 병목 시간 |

- 최소 스테이션 수·최소 병목 시간은 게임이 직접 계산(순서 고정 연속 분할 → 동적계획법). 숫자를 코드에 미리 박아 넣지 않음
- 클리어 시 결과 메시지: 별 · 점수 · 일 생산능력 · 효율

## 9. 금지 사항

- 실존 회사명·제품명·로고 사용 금지. 회사명은 "(가상) 동백정밀"만
- 기존 상용 게임의 이름·캐릭터·그림·효과음 모방 금지 (독자 디자인)
- 외부 라이브러리·CDN·폰트 서버 사용 금지 (오프라인 동작 조건)
- 서버·로그인·데이터 저장(전송) 기능 금지. 점수 저장이 필요하면 브라우저 localStorage까지만
- 레벨 정답(최소 스테이션 수·최적 배치)을 화면에 미리 표시 금지. 클리어 후에만 별로 확인
- `원본/` 파일 수정 금지. 게임은 `결과/` 폴더에 저장
