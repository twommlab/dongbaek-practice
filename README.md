## 열 설명

**생산실적**: 일자 / 라인 / 설비 / 조(주간·야간) / 품번 / 품명 / 계획수량 / 생산수량 / 양품수량(=생산−불량) / 불량수량 / 작업시간(분, 실제 가동) / 비가동시간(분, 정지) / 작업자수.
작업시간+비가동시간 = 그 품번에 배정된 시간. 설비 1대가 한 조(480분)에 품번 2개를 나눠 생산.

**불량내역**: 일자 / 라인 / 설비 / 조 / 품번 / 불량유형(치수불량·스크래치·버(Burr)·크랙·조립불량·찍힘) / 수량 / 조치내용.
일자·설비·조·품번으로 합치면 생산실적 불량수량과 같음.

**설비가동**: 일자 / 설비 / 조 / 계획가동(분, 480) / 실가동(분) / 정지사유(금형교체·고장·자재대기·품질점검·없음) / 정지시간(분) / 이론CT(초, 1개 만드는 이론 시간) / 생산수량.
- 가동률 = 실가동 ÷ 계획가동
- 성능가동률 = 생산수량 × 이론CT ÷ (실가동 × 60)
- 양품률 = 양품 ÷ 생산 (생산실적 파일)
- OEE = 가동률 × 성능가동률 × 양품률

**재고현황**: 품목코드 / 품명 / 구분 / 단위 / 기초재고 / 입고 / 출고 / 기말재고(=기초+입고−출고) / 안전재고 / 단가(원). 재고금액 = 기말재고 × 단가.

**출하실적**: 주차시작일(월요일) / 품번 / 품명 / 출하수량.
